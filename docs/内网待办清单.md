## ⭐ 开工第一步（阻断性）

- [ ] **T-1 先行**：用仓内自带的最小验证 agent **`ping`**（`adapters/opencode/.opencode/agents/ping.md`，操作命令见 README"部署"节）验证 codeagent（opencode 改造版）的实际约定，**通过后再全量部署**，否则可能白干：
  - agent 目录名：`.opencode/agent/`（单数）还是 `agents/`（复数）？当前 M1 用了复数，来源有冲突。
  - skill 发现规则、`skill` 工具行为。
  - `core/` **仓根相对路径**引用能否被 agent 正确解析（全仓 agent 加载类路径已统一为仓根相对；部署映射：软链 `ln -s adapters/opencode/.opencode .opencode`，已 gitignore）。
  - **中文路径实测**：Read/Glob/Grep 对中文文件名/目录名的处理。
  - **deny 权限连坐实测**：subagent 在 `edit/bash deny` 下 Read/Grep/Glob 是否可用（codeagent 若把 grep 改造为走 shell，`bash: deny` 会瘫痪只读挖掘——届时按其权限语义放行只读检索，如 `bash: { "grep *": allow, "*": deny }` 式配置）。
  - **迁移方式**：入内网走 `git clone`/`git bundle`，勿走 zip（中文文件名会被 Windows 解压按 GBK 猜码搞乱）；内网机建议 `git config core.quotepath false` 改善显示。
