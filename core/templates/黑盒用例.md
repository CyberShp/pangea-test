# 黑盒用例模板（通用占位版）

> 用途：主 Agent 基于统一风险卡产出单条黑盒或灰盒系统测试用例的统一格式。字段清单为架构 §4.5 的硬约束——**字段必须齐**。
> 溯源纪律：`外部触发手段` 遵守 R-7.2（触发必须外部）；`观测判据` 遵守 R-7.2（观测必须外部，禁止查内部变量）。
> `用例编号` 是 auditor `audit_opinion.checks.blackbox_executability.violations[].case_id` 的锚点（证据包 schema §4.3），**须全局唯一、可被引用**。

---

## 字段模板（单条用例）

- **用例编号**：`TC-<模块>-<序号>`（全局唯一；auditor case_id 引用此字段，填写指引：同一模块内递增，如 `TC-NVMET-TCP-001`）
- **用例名称**：一句话概括测什么（填写指引：动宾结构，如"反复建断链观测内存是否泄漏"）
- **预置条件**：执行前环境/配置/数据的既定状态（填写指引：写清组网、版本、初始资源计数等，保证可复现）
- **外部触发手段(R-7.2)**：用什么外部动作触发被测行为（填写指引：协议报文构造/CLI 命令/故障注入/压力施加/配置变更；禁止"调用内部函数"和直接修改内部变量）
- **操作步骤**：有序步骤（填写指引：逐条编号，每步是黑盒同学真能执行的动作）
- **观测手段**：从 `core/shared/观测手段目录.md` 选取（填写指引：写明类别——协议报文/CLI 回显/告警/日志/性能统计/错误码——及具体观测点）
- **观测判据(PASS/FAIL)**：PASS 与 FAIL 各自的外部可观测判定（填写指引：**只能依据外部现象**且判据尽量量化；反例 ❌"内部 `sk_state==TCP_ESTABLISHED`"，正例 ✅"CLI `show connection` 状态为已建立"）
- **推导方法论**：填**裸方法名**（如 `状态转换`、`边界值分析`，不写路径），注明本例由哪种方法论系统推导
- **覆盖目标（可选，供覆盖审计）**：本例覆盖的"状态/迁移 ID"或"边界点 ID"（由所用方法论的操作步骤标注产生；auditor 的 `coverage` 检查以此核对迁移表/边界清单是否全覆盖）
- **关联风险（可选）**：引透镜裸名或 SFMEA 条目编号（填写指引：如 `资源泄漏` 或 `SFMEA-NVMET-TCP-003`；无则留空）
- **插桩需求（可选）**：仅在需要系统级时序/故障控制时填写控制语义、参数、内部控制点、观测、恢复和开发协作；不生成插桩代码。用例状态标 `待插桩准备`。

## 示例用例（存储领域·演示每字段怎么填）

- **用例编号**：`TC-NVMET-TCP-001`
- **用例名称**：NVMe/TCP 反复建断链观测控制器侧内存泄漏
- **预置条件**：阵列开启 NVMe/TCP 端口并映射 1 个命名空间；主机侧 `nvme-cli` 就绪；记录初始内存基线（**黑盒判据以阵列侧内存统计/告警为准**；`/proc/slabinfo` 属白盒辅助通道，仅在有调试通道时作旁证，见观测手段目录的裁定）。
- **外部触发手段(R-7.2)**：主机侧脚本循环执行 `nvme connect` 建链后立即 `nvme disconnect` 断链（外部 CLI 动作），并穿插 TCP 层异常断链（`iptables` **DROP 全部该连接报文**制造静默断链，或注入 TCP RST 制造复位断链——注意"丢弃 RST"不会制造断链，反而掩盖断链）。
- **操作步骤**：
  1. 采集内存基线并记录连接计数（CLI `show connection`）。
  2. 循环执行 建链→下发少量 IO→异常断链，重复 10000 次。
  3. 每 1000 次采集一次内存统计与连接计数。
  4. 循环结束后静置 5 分钟，再采集一次（排除延迟回收）。
- **观测手段**：性能统计（阵列侧内存占用统计接口）+ CLI 回显（`show connection` 连接计数）+ 告警（内存水位告警）。
- **观测判据(PASS/FAIL)**：
  - **PASS**：内存占用在多轮建断链后回落至基线附近——阈值示范：**偏离基线 ≤5%（或 ≤X MB，阈值由产品规格定），且最后 3 个采样点不再上涨**；连接计数随建/断链正确增减、最终归零；无内存水位告警。
  - **FAIL**：内存占用随建断链次数单调上涨且静置后仍超阈值不回落；或连接计数只增不减（残留连接）；或触发内存水位告警。
  - （判据均为外部可观测且量化，未依赖任何内部变量。）
- **推导方法论**：`状态转换`（建链↔断链↔异常复位的状态迁移覆盖）。
- **覆盖目标**：迁移对 `LIVE→DISCONNECTING→释放`（异常复位迁移路径）。
- **关联风险**：`资源泄漏`（透镜）；对应 `SFMEA-NVMET-TCP-003`（异常断链路径漏释放 `cmd->req.sg`）。
