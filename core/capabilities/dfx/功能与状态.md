# 功能与状态能力包

## 关注问题

外部操作进入模块后是否遵循预期协议/业务状态，合法动作能否完成，非法或乱序动作是否被明确拒绝并回到可用状态。

## 代码信号与分析动作

- 入口、报文类型、命令分发、状态变量、状态迁移表、错误码和回调注册。
- 用 `主干追踪`、`分支枚举`、`状态机提取`、`协议报文收发路径` 建立“外部动作 -> 内部状态推进 -> 外部响应”的地图。
- 对每个异常分支给出外部进入方式；没有可靠入口时标为开发确认或插桩需求。

## 复用材料

- lenses：`韧性/异常输入健壮性.md`、`规格/对外规格符合性.md`。
- methods：`状态转换.md`、`等价类划分.md`、`判定表覆盖.md`、`端到端场景.md`。

## 风险卡重点

状态前置条件、乱序/重复操作、错误响应、清理后的再次建立和可观测协议行为。
