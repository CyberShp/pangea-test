# 性能与压力能力包

## 关注问题

在并发、满配、异常扰动和长稳条件下，性能是否达到基线/规格，是否出现提前拐点、长尾、背压失控或压力解除后不恢复。

## 代码信号与分析动作

- 热路径分配/拷贝/校验、全局锁、单 worker、线性查找、队列积压、批处理/中断合并、重试和背压。
- 从调用链识别外部可调负载维度：IO 大小、QD、连接数、并发主机、协议特性、故障扰动和运行时长。
- 输出阶梯压测与恢复对照，而不是仅给单点性能数值。
