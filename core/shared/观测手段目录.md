## 观测手段分类（M1 骨架）

### 1. 协议报文
- 抓包（tcpdump / 阵列侧抓包工具）观测：报文时序、字段值、异常报文（乱序/重传/复位/协议违例）、错误响应（如 NVMe/TCP 的 status code、iSCSI reject PDU）。
- 判据示例：`C2HData` 是否按预期返回；`CmdSN` 是否连续；建链握手是否完成。

### 2. CLI 回显
- 阵列 CLI 查询命令的输出：连接/会话状态、资源计数、配置项、统计值、版本。
- 判据示例：`show connection` 状态是否为已建立；连接数是否随建/断链正确增减。

### 3. 告警
- 阵列告警系统上报的告警条目：产生/恢复、级别、告警码、描述。
- 判据示例：链路故障是否触发对应告警；恢复后告警是否清除。

### 4. 日志
- 底软日志（内核/驱动/带内管理/BMC）：错误日志、状态变迁日志、异常栈。
- 判据示例：异常路径是否打出预期错误日志；日志中错误码是否正确。

### 5. 性能统计
- IOPS / 带宽 / 时延 / 队列深度 / 重传率等统计接口。
- 判据示例：注入退化条件后性能指标是否按预期变化；恢复后是否回升。

### 6. 错误码
- 命令/操作返回的错误码（协议层、CLI 层、管理接口层）。
- 判据示例：非法输入是否返回规格规定的错误码。

## 边界裁定：设备内 `/proc` 类观测

`/proc/slabinfo`、设备内 shell 统计等需要登入控制器的手段，**不属于严格黑盒六类**，统一定位为**白盒辅助通道**：仅在有调试通道时作旁证；黑盒用例的 PASS/FAIL 判据必须以六类外部手段（阵列内存统计接口、告警、CLI 计数等）为准。另：主机侧数据读回比对（数据面校验）是合法的第七类手段，按需单列。
