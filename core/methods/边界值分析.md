# 边界值分析法

> 当测试点存在数值规格（上下限、容量、长度、计数）时，缺陷高发于边界而非区间中部；本方法在每个边界的"临界点及其两侧"系统取值，解决"用例散落在合法区间中央、恰好漏掉 off-by-one 与越界"的完备性问题。

本方法回答"怎么系统推导用例（保边界覆盖完备性）"，不回答"该规格背后有什么风险"（那是 lenses/ 的职责，与本方法正交组合）。

## 适用特征（agent 识别信号）

看到测试点具备下列任一信号，就应选用本方法：

- **有数值规格/取值范围**：字段有最小值/最大值、有效区间（如 MTU、传输块大小、超时秒数）。
- **有队列深度/深度上限**：命令队列、SGL 条目数、未完成 I/O 数有容量上限。
- **有序号/计数器**：CmdSN、StatSN、DataSN 等按序递增且可能回绕的序号。
- **有长度/大小约束**：PDU 长度、Data Segment Length、名称字符串长度、KV 键值长度。
- **有连接数/资源数上限**：最大连接数、最大会话数、最大命名空间数。
- **代码里出现 `if (x > MAX)`、`>= limit`、边界比较、容量检查**（由 code-excavator 分支枚举/主干追踪剧本回传的证据包提示）。

## 操作步骤

1. **列边界清单**：从证据包/规格文档提取每个受限量的下限 min 与上限 max，以及特殊点（0、空、回绕点、对齐边界）。注明该量外部如何被设定与观测（协议字段、CLI 参数、抓包）。
2. **对每个边界取 5 点**：min−1、min、min+1、max−1、max、max+1（下越界、下临界、正常低端、正常高端、上临界、上越界）。资源受限时可裁剪为 min−1/min/max/max+1 四点基线。
3. **划分预期**：min..max 内取值 → 合法路径；min−1、max+1 → 越界，应被拒绝/截断/返回规格错误码，且不崩溃、不越界写。
4. **处理回绕与溢出**：对序号/计数器额外取"最大值→回绕到 0"的临界序列，验证回绕后仍按序。
5. **处理多维边界组合**：若一条用例同时受两个量约束（如队列深度 × 单命令块大小），对"两者同时取上临界"补一条组合用例（与数据组合测试衔接，此处只补最危险的角点）。
6. **补空/零/对齐边界**：长度=0、空 SGL、非对齐地址等易漏临界单独出例。
7. **标覆盖目标**：每条用例标注覆盖的"边界点 ID"，供覆盖审计核对每个边界是否两侧齐全。

## 存储领域示例：队列深度 / CmdSN / PDU 长度 / 最大连接数

- **队列深度（如 NVMe/TCP SQ 深度或 iSCSI 未完成命令数上限 N）**：取值 depth = N−1、N、N+1。构造手段：用压测工具以固定 QD 下发 I/O，把在飞 I/O 数顶到 N 与 N+1。观测：N+1 时目标端是否按协议流控（如 iSCSI MaxCmdSN 窗口关闭、NVMe SQ 满不再取命令），而非丢命令或崩连。
- **CmdSN 序号**：取 ExpCmdSN 窗口边界与回绕点。构造乱序/越窗 CmdSN，观测目标是否按 MaxCmdSN 窗口拒绝越窗命令；把 CmdSN 推到 0xFFFFFFFF 后 +1 验证回绕到 0 仍被正确接受。
- **PDU 长度 / Data Segment Length**：取 0、协商的 MaxRecvDataSegmentLength 及其 +1。构造超长 Data Segment PDU，观测是否按协商值拒绝或分片，不发生缓冲越界（黑盒侧看应答码与连接是否存活）。
- **最大连接数/会话数**：并发建到 max、max+1 条连接，观测第 max+1 条是否被规范拒绝（应答码/建连失败）而非影响既有连接。

## 产出映射

每条推导出的用例填入 `templates/黑盒用例.md` 对应字段：

- **测试步骤/触发手段** ← 步骤 2 的取值 + 示例中的构造手段：写清如何用外部工具把受限量设到该边界点（压测 QD、构造特定长度 PDU、并发建连数）。
- **预期结果/观测判据** ← 步骤 3 的预期：合法点应成功、越界点应按规格拒绝/截断并给出可观测反馈（应答码、流控窗口、建连失败、连接仍存活），给出 PASS/FAIL 判据，严禁依赖内部变量（R-7.2）。
- **优先级/关联风险** ← 由 lenses/ 透镜（如资源泄漏、可靠性-数据完整性）标注，与本方法正交，不在此处产生。
- **覆盖目标** ← 步骤 7 标注的"边界点 ID"，供覆盖审计核对每个边界是否 min/max 两侧齐全。
- **推导方法论** ← 回填本方法名「边界值分析」，标明该用例由边界取点系统推导，便于评审追溯完备性来源。
