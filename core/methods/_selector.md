# methods/ 选择表（测试点特征 → 推荐方法）

> 本表是用例推导环节的入口：agent 拿到一个测试点，先按"识别信号"在此表定位应选的方法论文件，再进入该文件按操作步骤系统推导用例。
>
> 与 `lenses/` 正交：本库回答"怎么系统推导用例（保完备性）"，`lenses/` 回答"找什么风险（定优先级）"。二者组合使用——透镜扫出风险点，方法论把该点推成完备用例集。

## 方法间常见衔接（供组合推导）

- 等价类划分 ↔ 边界值分析：先分组取代表值，再对每组边界取临界点。
- 数据组合测试 ↔ 判定表覆盖：参数组合爆炸时用判定表约束到条件-动作矩阵。
- 处理周期测试 ↔ 时间维度覆盖：周期性处理叠加长稳/老化维度。
- 数据生命周期 ↔ 资源泄漏透镜（lenses/）：生命周期各阶段的资源配对由透镜定风险、方法论推完备用例。
- 端到端场景 ↔ 状态转换：端到端链路串起多状态机的关键路径。
