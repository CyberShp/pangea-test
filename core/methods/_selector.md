# methods/ 选择表（测试点特征 → 推荐方法）

> 本表是用例推导环节的入口：agent 拿到一个测试点，先按"识别信号"在此表定位应选的方法论文件，再进入该文件按操作步骤系统推导用例。
>
> 与 `lenses/` 正交：本库回答"怎么系统推导用例（保完备性）"，`lenses/` 回答"找什么风险（定优先级）"。二者组合使用——透镜扫出风险点，方法论把该点推成完备用例集。
>
> 状态：M1 仅落地 2 个种子方法（状态转换 / 边界值分析），其余 10 个方法为 M3 待补占位（见文末）。选到占位方法时，暂回退到最接近的种子方法并在产出中标注"方法论待补（M3）"。

## 选择表（M1 已落地）

| 测试点特征（识别信号） | 推荐方法 | 方法文件 |
|---|---|---|
| 有状态机 / 会话·连接生命周期 / 当前状态决定操作是否合法 / 超时异常引发状态跃迁 | 状态转换 | [状态转换.md](状态转换.md) |
| 有数值规格·取值范围 / 队列深度·容量上限 / 序号·计数器 / 长度·大小约束 / 连接数·资源数上限 | 边界值分析 | [边界值分析.md](边界值分析.md) |

一个测试点可命中多行（如"最大连接数状态机"既有边界又有状态），此时两法都用、用例集合并去重。
