# MAE 流程覆盖法

> MAE = 管理操作（Manage）/ 告警（Alarm）/ 事件（Event）三条运维流程。<!-- 待校准：MAE 的确切展开以团队既有约定为准，此处按存储管理面"管理-告警-事件"理解，若团队含义不同请回填修正 --> 当测试点属于阵列可服务性/运维面时，缺陷常藏在"操作触发了状态变化，但对应的告警/事件没正确产生、消除或上报"；本方法沿管理操作 → 告警 → 事件的联动链系统出用例，解决"只验了操作成功、漏掉配套告警与事件流"的完备性问题。

本方法回答"怎么系统推导用例（保 MAE 运维流程覆盖完备性）"，不回答"运维面哪里有什么风险"（那是 lenses/ 的职责，尤其与可服务性透镜正交组合）。

## 适用特征（agent 识别信号）

看到测试点具备下列任一信号，就应选用本方法：

- **属阵列管理面/可服务性范畴**：CLI/管理接口的配置操作、告警上报、事件日志、性能统计、错误码。
- **操作应联动告警/事件**：创建/删除/故障/恢复动作预期产生对应告警产生或消除、事件记录。
- **有告警生命周期**：告警产生→持续→消除→恢复，需闭环。
- **有事件审计/日志流**：关键操作留事件、可查询、可搜索、可批量导出。
- **可服务性透镜扫出运维路径**（本法与 `core/lenses/可服务性.md` 是天然搭档：透镜找运维风险，本法保运维流程覆盖）。

纯数据面 IO 链路用端到端场景；本法专治管理-告警-事件联动。

## 操作步骤

1. **列管理操作清单（M）**：枚举被测的运维操作（创建/删除/修改/启停/升级/切换），标注外部触发手段（CLI/管理 API）与成功回显。
2. **建操作→告警映射（A）**：对每个操作/故障场景，列出预期产生或消除的告警，标注告警级别、外部观测通道（告警查询接口/北向上报/CLI）。
3. **建操作→事件映射（E）**：列出预期记录的事件/审计日志，标注可查询手段与关键字段。
4. **正向联动出例**：每个操作出一条用例，同时验证 (a) 操作成功、(b) 配套告警按期产生/消除、(c) 事件正确落记。三者缺一即 FAIL。
5. **告警闭环出例**：制造故障→观测告警产生→恢复故障→观测告警消除，验证告警不残留、不误报、不漏报。
6. **事件可服务性出例**：验证事件可查询、可按条件搜索、可批量导出、名称/ID 查询正确（呼应可服务性维度）。
7. **异常/边界联动**：告警风暴抑制、重复操作幂等、无权限操作是否留审计事件。
8. **标覆盖目标**：每条用例标注覆盖的"操作 ID / 告警 ID / 事件 ID"，供覆盖审计核对 M-A-E 三面是否齐全。

覆盖准则：每管理操作的操作结果 + 告警联动 + 事件记录三面齐验为基线；告警闭环单独覆盖。

## 存储领域示例：端口/链路管理 / 容量告警 / 权限审计

- **端口/链路管理联动**：CLI 禁用某前端端口（M）→观测链路 down 告警产生（A）、操作事件落记（E）；重新启用→告警消除、恢复事件记录。验证主机侧连接相应中断/恢复。
- **容量水位告警闭环**：写入数据把池容量顶到告警阈值（M/触发）→观测容量告警产生（A）与事件（E）；释放空间→告警消除。验证阈值去抖不误报（配合处理周期测试）。
- **权限与审计事件**：以不同角色下发管理操作，无权限操作被拒（M）→观测是否仍留审计事件（E）、是否产生安全告警（A）。验证事件可按操作者/时间搜索、可批量导出。
- **升级流程联动**：发起升级（M）→观测升级进度事件流（E）、异常时告警（A）、前向版本兼容期间的告警/事件正确性。

## 产出映射

每条推导出的用例填入 `core/templates/黑盒用例.md` 对应字段（左端为模板精确字段名）：

- **外部触发手段 + 操作步骤** ← 步骤 1/4–7 的操作与故障构造：写清如何用外部手段下发管理操作、制造故障、恢复故障（CLI 命令、管理 API、故障注入）。
- **观测手段 + 观测判据（PASS/FAIL）** ← M-A-E 三面的外部现象：操作回显成功、告警按期产生/消除、事件正确落记且可查，判据外部可观测，严禁查内部变量（R-7.2）；观测手段从 `core/shared/观测手段目录.md` 选（告警/日志/CLI 回显/性能统计/错误码）。
- **关联风险** ← 由 lenses/ 透镜（尤其可服务性）标注，与本方法正交，不在此处产生（风险优先级在 SFMEA 的 S·O·D 承载，用例模板无独立优先级字段）。
- **覆盖目标** ← 步骤 8 标注的"操作 ID / 告警 ID / 事件 ID"，供覆盖审计核对 MAE 三面是否齐全。
- **推导方法论** ← 回填裸方法名「MAE流程覆盖」（不写路径），标明该用例由管理-告警-事件联动链系统推导，便于评审追溯完备性来源。
