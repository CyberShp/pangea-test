# 异常输入健壮性透镜（DFX 维度：韧性）

> 一句话：找"畸形报文/非法参数/模糊输入能把设备打崩或打乱"的隐患——协议解析、参数校验、长度/类型/状态检查必须在任意恶意或损坏输入下稳健，绝不崩溃、不越界、不泄漏、不进入未定义状态。

## 风险机理

阵列对外接口面对不可信输入（异构主机、有 bug 的 initiator、恶意构造、链路损坏后的坏帧）。健壮性缺口在畸形输入下暴露为崩溃、越界、死循环、状态错乱。典型成因：
- **长度字段可信**：直接用报文自带的长度/计数字段做拷贝/循环/分配，未校验其合理性（超长、为 0、为负、与实际不符）。
- **缺字段/类型/状态校验**：未知 PDU 类型、非法枚举值、保留位置位、非法状态下收到不该收的报文未被拦截。
- **分片/重组不设防**：畸形分片、乱序、重叠、超量分片导致重组逻辑越界或耗尽内存。
- **解析递归/循环无界**：TLV/嵌套结构解析对深度/数量无上限，构造输入触发死循环或栈溢出。
- **数值解析异常**：整型溢出、除零、符号错误在长度/偏移计算中放大成越界。

## 代码特征模式（供 context-pack obligation 使用的扫描指引）

以下为风险扫描剧本对本对象的 grep/阅读指令，命中即记 `文件:行号` + 机理（示例锚点均为示意）：
- **信任外部长度**：`memcpy(.*, len)|alloc(len)|for (i < .*count)` 中 len/count 来自报文字段——是否先校验上界/非零/与实际帧长一致。
- **PDU 类型/枚举分发**：`switch (pdu_type)|case .*:` 是否有 `default` 兜底拒绝；未知类型/保留值是否被安全丢弃而非落到未定义分支。
- **状态机非法输入**：状态判断（`if (state == )`）是否覆盖"非法状态下收到该报文"，缺失即状态错乱嫌疑。
- **整型运算**：长度/偏移计算中的 `+ - *`（`offset + len`、`a * b`）是否可溢出绕过后续边界检查；有无 `check_add_overflow` 类保护。
- **分片/重组**：`reassembl|fragment|segment|coalesce` 路径对分片数/重叠/超量的防护。
- **免疫判断**：若对象只处理内部可信数据、输入已在上游严格校验，则给"免疫理由"（并注明其可信边界依赖）。

- （通用示意）iSCSI 目标端解析 PDU 时直接采信 BHS 中的 DataSegmentLength 做缓冲拷贝，未与实际收到字节数比对，构造超长声明触发越界读，连接复位或控制器崩溃。

## 黑盒触发手段

存储领域把畸形输入打进去的手段：
- **协议模糊测试（fuzz）**：对建链/协商/数据 PDU 各字段做变异（长度、类型、保留位、序列号、Digest），大批量灌入。
- **构造畸形报文**：超长/零长/负长声明、未知 PDU 类型、非法状态下的 PDU、重叠/超量分片、错误 Digest。
- **非法参数/命令**：CLI/管理接口传非法参数、超范围值、错误类型、缺必填项。
- **损坏链路重放**：注入坏帧、截断帧、乱序帧，模拟链路损坏后的脏输入。

## 观测判据（从 core/shared/观测手段目录.md 选手段）

判 PASS/FAIL 的外部现象（全部外部可观测）：
- **可用性（首要）**：任何畸形输入下设备不崩溃、不挂死、不重启，其它合法连接/IO 不受影响；崩溃或殃及无辜 = FAIL。
- **协议报文**：畸形报文应被规范拒绝或安全丢弃——抓包见规范的 reject/status 或按标准终止连接（如 Header Digest 错误 FES=3h），而非无响应挂死或错误接受。
- **错误码**：非法参数/命令返回规格约定的错误码，可预期且一致。
- **告警/日志**：畸形输入应打出规范错误日志/告警，含正确错误码；不应出现越界访问栈、panic 栈。
- **资源交叉**：模糊测试期间及之后无内存/连接泄漏（畸形输入不应制造资源单调累积）。

## 用例骨架

- **用例雏形 1｜协议字段模糊不崩溃**：预置目标端 + 并行合法业务 → 外部触发：对 PDU 各字段大批量变异灌入 → 观测手段：可用性（设备/合法业务存活）+ 抓包响应 + 告警日志 → 判据：设备不崩、合法业务不受影响、畸形被规范拒绝/丢弃，崩溃或误接受判 FAIL。推导方法论：错误推测 / 边界值分析（M3 待补；过渡期按 `_selector` 规则回退种子方法并标注）。关联风险：本透镜。
- **用例雏形 2｜非法长度声明不越界**：预置目标端 → 外部触发：构造超长/零长/不一致长度声明的 PDU → 观测手段：可用性 + 错误码 + 日志 → 判据：被拦截并返约定错误码、无越界/崩溃、无资源泄漏。推导方法论：边界值分析（长度边界）。关联风险：本透镜（内部实现规格交叉）。
