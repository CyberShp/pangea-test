## 骨架约定（种子透镜文件结构，R-6.2）

每个透镜文件遵循统一骨架：
1. 标题 + 一句话（本透镜找什么风险）
2. `## 风险机理`（这类失效为什么发生）
3. `## 代码特征模式`（给 excavator 的 grep/阅读扫描指引 = 风险扫描剧本读取的核心栏）
4. `## 典型历史缺陷`（团队回填位 `<!-- 团队回填：历史缺陷案例 -->` + 通用示意）
5. `## 黑盒触发手段`（怎么从外部逼出风险）
6. `## 观测判据`（判 PASS/FAIL 的外部现象，从 `shared/观测手段目录.md` 选手段）
7. `## 用例骨架`（1-2 条用例雏形，指向 `templates/黑盒用例.md` 格式）
