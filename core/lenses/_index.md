# DFX 风险透镜库索引

> 本库回答"**找什么风险**"（R-6.1 两库正交：与 `methods/`"怎么推用例"组合使用）。
> 按团队 DFX 维度归类（R-6.2）。**全量初稿已落地（18 个透镜，覆盖 6 个 DFX 维度 + 可服务性引用桩）**；内容由 Claude 起草，"典型历史缺陷"栏待团队回填，条目可增删。
>
> **透镜双消费模式**（R-6.2）：
> - 全量分析场景 = **全透镜浅扫**（每个透镜过一遍，有特征→入 SFMEA，无特征→一句话免疫说明）；
> - 专项风险场景 = **单透镜深钻**到用例级。
>
> **消费入口**：内部 DFX 子 Agent 通过 `风险扫描` playbook 加载透镜的“代码特征模式”；六个能力包的装配关系见 `core/capabilities/_index.md`。透镜不再是用户可切换的专家。

## 新 DFX 归属

18 个透镜按新架构归并为：功能与状态（异常输入、对外规格）、资源与规格（内部规格、资源泄漏、过载保护）、性能与压力（性能退化、长尾、资源争用）、并发与异常（并发、异常处理）、升级与兼容（版本兼容、升级中断回滚）、可靠性与一致性（超时恢复、数据完整性、恢复路径、单点、降级、故障注入）。可服务性为所有风险卡的共同必填观测字段。

## 骨架约定（种子透镜文件结构，R-6.2）

每个透镜文件遵循统一骨架：
1. 标题 + 一句话（本透镜找什么风险）
2. `## 风险机理`（这类失效为什么发生）
3. `## 代码特征模式`（给 excavator 的 grep/阅读扫描指引 = 风险扫描剧本读取的核心栏）
4. `## 典型历史缺陷`（团队回填位 `<!-- 团队回填：历史缺陷案例 -->` + 通用示意）
5. `## 黑盒触发手段`（怎么从外部逼出风险）
6. `## 观测判据`（判 PASS/FAIL 的外部现象，从 `core/shared/观测手段目录.md` 选手段）
7. `## 用例骨架`（1-2 条用例雏形，指向 `core/templates/黑盒用例.md` 格式）
