# 性能退化透镜（DFX 维度：性能）

> 一句话：找"稳态吞吐/IOPS 会塌陷、有效 IO 路径被悄悄拉长"的隐患——锁粒度过粗、串行化点、批处理退化、拷贝/校验冗余，让阵列在压力或特定配置下从"应有的高水位"跌到远低于规格的水平。

## 风险机理

存储阵列的性能规格（IOPS、带宽、单路吞吐）是承诺指标；任何"每个 IO 多走一段、多抢一次锁、多拷一次"的缺口在高并发下被 QD/连接数放大，稳态吞吐塌陷或带宽打不满。典型成因：
- **锁争用/粒度过粗**：热路径持大锁（全局队列锁、全局统计锁），并发上不去；本该 per-queue/per-CPU 的资源被全局串行化。
- **串行化点**：本可并行的下发/完成被单线程/单队列漏斗收口（单一 completion 线程、全局 tasklet），核数增加不涨性能。
- **路径变长**：某配置下走了慢路径（未命中快路径、退化为逐 SGL 拷贝、Digest 全量重算、未走 zero-copy/DMA 直通）。
- **批处理退化**：合并/聚合窗口失效，doorbell/中断/PDU 变成一 IO 一次，系统调用与中断风暴。
- **算法复杂度**：查表/查找在连接数或命令数增大后退化为 O(n) 甚至 O(n²)（线性扫链找 cmd、找 tag）。

## 代码特征模式（给 excavator 的扫描指引）

以下为风险扫描剧本对本对象的 grep/阅读指令，命中即记 `文件:行号` + 机理（示例锚点均为示意）：
- **热路径持锁**：IO 下发/完成路径（`.*_queue_rq|.*_submit|.*_complete|.*_recv|.*_process_pdu`）内的 `spin_lock|mutex_lock|spin_lock_irqsave`。判断锁范围是否覆盖了拷贝/校验/内存申请等重活；是否可缩小临界区或改 per-CPU。
- **全局串行点**：`global|shared|g_` 前缀的队列/计数/链表 + 单一 worker/线程（`kthread_create|INIT_WORK|tasklet_init` 只一个实例）承接所有 IO 完成。核数扩展性存疑点。
- **慢路径回退**：`fallback|slow_path|memcpy|copy_from_iter|csum|crc|digest` 在数据面每 IO 命中——核对是否本可 zero-copy/硬件卸载却走了软件全量拷贝/校验。
- **线性查找**：`list_for_each.*cmd|for .*tag|find_.*by_.*` 在下发/完成路径按 CmdSN/tag/句柄线性扫描；随队列深度/连接数增长的复杂度点。
- **批处理/聚合**：doorbell、中断合并、PDU 聚合（`.*_ring_doorbell|coalesce|batch|nvmet_tcp_.*queue_response`）是否每 IO 触发一次而非按窗口聚合。
- **免疫判断**：若对象为纯控制面、低频配置路径、无数据面 IO，则给"免疫理由"（非性能敏感路径，供全透镜浅扫一句话说明）。

## 黑盒触发手段

存储领域从外部把性能退化压出来的手段：
- **阶梯加压**：fio/vdbench 逐档拉升 QD、连接数、jobs，绘制 IOPS/带宽随并发的曲线，找拐点与塌陷点。
- **多连接/多队列扩展**：从单连接单队列扩到多连接多队列多主机，验证线性扩展性；不涨即串行化嫌疑。
- **配置对照**：开/关 Header Digest、Data Digest（HDGST/DDGST），大/小 IO，顺序/随机，对比是否某配置掉入慢路径。
- **长稳基线比对**：与历史基线/规格值对比稳态吞吐；持续跑观察是否随时间缓降。

## 观测判据（从 core/shared/观测手段目录.md 选手段）

判 PASS/FAIL 的外部现象（全部外部可观测）：
- **性能统计**：IOPS/带宽/单路吞吐达到规格水位；随 QD/连接数应单调上升至平台期而非提前塌陷或回落；某配置切换后不应出现断崖式下降。低于规格阈值或曲线拐点异常 = FAIL。
- **CLI 回显**：`show performance`/统计接口的稳态吞吐值应落在规格区间；队列深度统计不应长期堆积（下发快、完成慢的串行化征兆）。
- **告警**：不应出现性能劣化/背压类告警。
- **日志**：不应频繁出现慢路径/重试/背压相关日志刷屏。
- **协议报文**：抓包观测有效载荷占比与 PDU 聚合度——若每 IO 拆成过多小 PDU、往返变多，是路径变长/批处理退化的外部旁证。

## 用例骨架

> 格式见 `core/templates/黑盒用例.md`（字段：用例编号/用例名称/预置条件/外部触发手段/操作步骤/观测手段/观测判据/推导方法论/覆盖目标/关联风险）。

- **用例雏形 1｜并发扩展吞吐不塌陷**：预置稳定链路与基线 → 外部触发：fio 阶梯拉升 QD/连接数 → 观测手段：性能统计（IOPS/带宽曲线）+ CLI 吞吐 → 判据：达规格水位、随并发单调升至平台期，出现提前塌陷/回落判 FAIL。推导方法论：处理周期测试 / 时间维度覆盖（M3 待补；过渡期按 `_selector` 规则回退种子方法并标注）。关联风险：本透镜。
- **用例雏形 2｜配置切换不掉慢路径**：预置目标端 → 外部触发：开关 HDGST/DDGST、切大小 IO 各跑基准 → 观测手段：性能统计 + 抓包 PDU 聚合度 → 判据：各配置吞吐落规格区间，无某配置断崖下降。推导方法论：边界值分析（配置边界）。关联风险：本透镜。
