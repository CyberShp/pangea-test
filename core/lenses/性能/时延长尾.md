# 时延长尾透镜（DFX 维度：性能）

> 一句话：找"平均时延好看、但 P99/P999 尾巴甩得很长"的隐患——周期性停顿（GC、刷盘、日志落盘、锁等待、批量元数据操作）在长尾上制造抖动与超时，均值掩盖了个别 IO 的秒级卡顿。

## 风险机理

存储 SLA 常以尾时延（P99/P999/P9999）与抖动约束，而非均值。任何"偶发但规律的长停顿"都会在长尾放大，触发主机侧 IO 超时、重试、路径切换。典型成因：
- **周期性停顿**：后台刷盘/落盘、日志回卷、检查点、缓存回收、GC/内存整理在前台 IO 路径上抢锁或抢带宽，制造周期性尖峰。
- **锁等待长尾**：多数 IO 不竞争、少数 IO 撞上持锁的慢操作（元数据更新、统计聚合），排队时延突增。
- **队头阻塞（HoL）**：单队列/单连接上一个大 IO 或慢 IO 阻住后续小 IO；无 QoS/优先级隔离。
- **重传/退避尖峰**：TCP 重传、拥塞退避、乱序重组等待，把个别 IO 拖到 RTO 级别。
- **批量操作抖动**：批量建链/断链、批量下刷、后台迁移抢占前台资源，尾时延随之跳变。

## 代码特征模式（给 excavator 的扫描指引）

以下为风险扫描剧本对本对象的 grep/阅读指令，命中即记 `文件:行号` + 机理（示例锚点均为示意）：
- **前台路径中的重活**：IO 完成/下发路径（`.*_complete|.*_submit|.*_recv`）中调用刷盘/落盘/同步（`.*flush|.*sync|fsync|wbc|writeback|kmalloc(GFP_KERNEL)` 可能睡眠）——前台被后台重活阻塞的点。
- **周期任务与前台共享资源**：定时器/后台线程（`timer_setup|mod_timer|schedule_delayed_work|kthread`）与前台是否争同一把锁、同一条带宽/队列。列出共享边界。
- **粗粒度睡眠锁**：前台路径持 `mutex_lock`/可睡眠锁跨越 IO/内存/网络等待，导致排队长尾。
- **无优先级/QoS 隔离**：单一队列承载大小 IO 混跑（`.*_queue` 无分级、无 SGL 大小分流），队头阻塞嫌疑。
- **重传/超时/退避**：`retransmit|rto|backoff|retry|timeout` 在数据面路径的触发条件与放大关系。
- **免疫判断**：若对象为一次性配置操作、无前台 IO、无周期后台交互，则给"免疫理由"（非尾时延敏感路径）。

## 黑盒触发手段

存储领域从外部把长尾逼出来的手段：
- **尾时延采集压测**：fio/vdbench 固定 QD 长跑，采集完整时延直方图（P50/P99/P999/P9999/max），而非只看均值。
- **混合负载/HoL 构造**：大 IO 与小 IO 混跑、顺序与随机混跑，制造队头阻塞与优先级竞争。
- **后台事件对齐**：在跑测期间触发刷盘/快照/后台迁移/批量建断链，观察尾时延尖峰是否与后台事件时间对齐。
- **长稳抖动观测**：数小时 soak，记录时延随时间的抖动包络，找周期性尖峰节律。

## 观测判据（从 core/shared/观测手段目录.md 选手段）

判 PASS/FAIL 的外部现象（全部外部可观测）：
- **性能统计**：时延直方图的 P99/P999/max 落在 SLA 阈值内；抖动包络平稳、无规律性尖峰。尾时延超阈或周期性尖峰 = FAIL（均值达标不足以判 PASS）。
- **协议报文**：抓包观测单 IO 往返时延、重传与乱序——出现规律性重传/RTO 级停顿即长尾外部证据。
- **告警**：不应出现 IO 超时/时延劣化类告警。
- **日志**：不应出现前台 IO 被后台阻塞、超时重试相关日志的周期性刷屏。
- **CLI 回显**：`show performance` 的时延分位统计不应长期偏离基线；主机侧不应观测到 IO 超时/路径切换。

## 用例骨架

- **用例雏形 1｜稳态尾时延达标**：预置稳定链路与 SLA 阈值 → 外部触发：固定 QD 长跑并采集时延直方图 → 观测手段：性能统计（分位数/max）+ 抓包往返 → 判据：P99/P999/max 落 SLA 内、无规律尖峰，超阈或周期尖峰判 FAIL。推导方法论：时间维度覆盖 / 处理周期测试（M3 待补；过渡期按 `_selector` 规则回退种子方法并标注）。关联风险：本透镜。
- **用例雏形 2｜后台事件不污染前台尾时延**：预置前台 IO 稳态 → 外部触发：期间叠加刷盘/快照/批量建断链 → 观测手段：时延分位随时间序列 + 日志时间对齐 → 判据：后台事件期间尾时延尖峰不超阈、不与后台事件强相关。推导方法论：状态转换（前台/后台并发态）。关联风险：本透镜。
