# Test design method

测试设计只消费已经确认的 canonical risk、风险的 `testability` 和冻结语义，不参与风险是否成立的判定。

1. 对 `blackbox_ready` 风险，使用外部输入、退出码、日志、文件或协议可见结果设计场景。
2. 对 `graybox_ready` 风险，明确所需的内部观测点，但不得把推测写成已存在的接口。
3. 对 `blocked` 风险不生成可执行用例；风险及其缺失证据继续保留在正式结果中。
4. 场景参数给出有限代表值和边界值；测试用例为每个参数选择一个具体值。
5. 前置条件、步骤、预期结果、观测点和清理动作必须可执行且相互对应。
6. 测试覆盖关系必须精确绑定风险和语义对象，禁止把所有用例机械绑定全部风险。
